# X 隐私遮罩

在 X / Twitter 页面遮住自己的账号卡、头像和身份信息，减少办公、演示或录屏时意外露出账号的情况。无需注册，无需配置密钥，设置保存在浏览器本地。

**[下载最新版](https://github.com/ChaseMoneyChaseFame/x-privacy-mask/releases/latest)** · [反馈问题](https://github.com/ChaseMoneyChaseFame/x-privacy-mask/issues)

## 下载安装

当前提供 GitHub 手动安装版，尚未上架扩展商店。适用于支持加载 Manifest V3 扩展的桌面 Chromium 浏览器；Chrome、Edge、Arc、Dia 的真实兼容性仍需使用者验证。不支持 Safari、Firefox 或手机浏览器。

1. 打开上面的下载页，在 **Assets** 中下载 `x-privacy-mask-v0.1.2.zip`。不要选 `Source code`。
2. **解压 ZIP**，把解压后的文件夹放在一个长期保留的位置。
3. 打开浏览器的扩展管理页：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`；其他浏览器从菜单进入“管理扩展程序”。
4. 开启右上角的 **开发者模式**，点击 **加载已解压的扩展程序**。
5. 选择解压后直接包含 `manifest.json` 的文件夹。
6. 打开或刷新 [x.com](https://x.com/)，在浏览器工具栏的扩展菜单中找到 **X Privacy Mask**。

安装后无需运行命令或安装 Node.js。请保留解压文件夹：浏览器会直接从这个目录加载扩展。

## 遮罩范围

| 开关 | 默认状态 | 作用 |
| --- | --- | --- |
| 隐私模式 | 开启 | 所有遮罩的总开关 |
| 左下角账号卡 | 开启 | 隐藏账号卡，鼠标悬停时临时显示 |
| 页面身份 | **关闭** | 遮住可识别的本人头像和身份链接，包括发帖与回复框、自己的帖子和个人主页 |

**要遮住回复框旁的头像，请同时开启“隐私模式”和“页面身份”。** 其他用户的头像不属于遮罩范围。快捷键 `Alt/Option + Shift + X` 可切换总开关；如有冲突，可在浏览器的扩展快捷键设置中调整。

## 更新与卸载

- **更新：**下载新版 ZIP，解压并用新版文件替换原安装目录中的文件，在扩展管理页点击“重新加载”，再刷新 X 页面。GitHub 手动安装版不会自动更新。
- **卸载：**在扩展管理页点击“移除”，之后可删除解压文件夹。
- 从源码安装时，在扩展管理页加载仓库内的 `extension/` 文件夹即可。

## 常见问题

**回复框头像仍然显示？** 先确认“页面身份”已开启，再确认已重新加载新版扩展并刷新 X。若仍有遗漏，请在 Issues 中说明浏览器版本、扩展版本和出现位置；附图前先遮住自己的账号信息。

**找不到 `manifest.json`？** 需要先解压 ZIP，再选择包含该文件的目录。若下载的是源码压缩包，目标目录是解压后的 `extension/`。

**为什么左下角悬停后又显示了？** 这是临时查看账号的设计。移开鼠标后会恢复遮罩；录屏时注意不要把鼠标停在账号卡上。

## 隐私与限制

- 只在 `https://x.com/*` 和 `https://twitter.com/*` 页面运行。
- 设置仅存于 `chrome.storage.local`；不读取或保存密码、Cookie、访问令牌，不包含统计 SDK，也不发送网络请求。
- 账号标识只在页面运行期间用于匹配当前用户，扩展弹窗会显示检测到的账号。
- 遮罩只改变页面显示，不删除网页中的账号数据；不会遮住地址栏、系统通知或已保存的截图。
- 依赖 X 的页面结构和当前账号卡识别，不能保证遮住所有身份信息。X 更新页面结构后可能需要适配。
- `0.1.1` 已通过单元测试、静态权限校验和模拟 X DOM 的无界面 Chromium 回归测试；真实 X 页面上的新版效果仍待验证。

## 开发与检查

本项目使用原生 JavaScript，无构建步骤。安装 Node.js 22+ 后运行：

```sh
npm test
npm run validate
npm run package
```

打包命令需要 `zip`，会生成 `dist/x-privacy-mask-v<版本号>.zip`。安装包包含扩展文件、本说明和 MIT 协议，不包含开发环境或个人项目记录。

模拟浏览器回归测试需要额外安装 Playwright 和 Chromium：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

测试在独立无界面浏览器内执行，不使用个人浏览器登录态，也不访问实际 X 账号。若已有 Playwright 环境，可以用 `NODE_PATH` 指向其 `node_modules` 目录。
